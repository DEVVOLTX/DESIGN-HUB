## ✨ Overview

Design Hub هو موقع مصمم خصيصاً لمساعدة المصممين والمبدعين والفرق الرقمية في الوصول إلى مصادر التصميم المميزة بسرعة وسهولة.

بدلاً من البحث في الإنترنت بشكل متفرق، يوفر المشروع واجهة أنيقة وقابلة للتصفح تحتوي على قائمة منظمة من أفضل المواقع التي تساعد في:

- اختيار الألوان
- البحث عن الصور والموكابز
- تنزيل الأيقونات والفرش والملفات
- استلهام تصاميم UI/UX
- اكتشاف فيديوهات ومراجع تصميم أنيقة

---

## 🌟 Features

- واجهة جذابة ومتجاوبة بالكامل
- تصنيفات منظمة ومقسمة بوضوح
- بحث سريع حسب الاسم أو الرابط أو التصنيف
- فلترة حسب النوع والخيارات المجانية والمدفوعة
- إمكانية حفظ المصادر المفضلة محلياً في المتصفح
- نسخ الرابط بسرعة
- تصميم حديث بأسلوب احترافي ومميز

## ▶️ How to Run

### Option 1: Open directly

افتح ملف `index.html` مباشرة في المتصفح.

### Option 2: Use a local server

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

---

## 🚀 How to Use

1. اختر الفئة المناسبة من القائمة الجانبية
2. استخدم البحث للعثور على أي مصدر بسرعة
3. مرر بين الفلاتر مثل: مجاني، مدفوع، صور، أيقونات، فيديوهات...
4. اضغط على المصدر لفتحه مباشرة
5. استخدم زر الإضافة إلى المفضلة لحفظ المصادر المهمة
6. استخدم زر النسخ لنسخ الرابط بسرعة
